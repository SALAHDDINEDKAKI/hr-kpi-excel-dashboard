# HR KPI Excel Dashboard

An interactive HR analytics dashboard built entirely in Microsoft Excel, tracking core workforce metrics for a company of 200 employees using PivotTables, PivotCharts, and slicers — no external tools required to explore it.

## What this is

I wanted a project that showed Excel used the way an HR or People Ops team would actually use it day to day — not just formulas in a spreadsheet, but a single-page dashboard someone could open, filter by department, and pull real answers from without touching the raw data.

## KPIs tracked

- **Total Headcount** — 156 active employees
- **Attrition Rate** — 22.0%
- **Average Tenure** — 5.8 years
- **Gender Split** — 50.6% female / 49.4% male
- **Average Salary by Department** — ranges from $44.3K (Customer Support) to $72.1K (Engineering), across 7 departments
- **Performance Rating Distribution** — ratings 1–5, with the bulk of employees rated 3 (77) and 4 (63)

## Tools & skills used

- PivotTables & PivotCharts
- COUNTIFS / AVERAGEIFS formulas
- Excel Tables (structured references)
- Slicers for interactive filtering by department
- Dashboard layout and formatting, built for a single-screen view

## How to explore it

Open `hr_employee_data.xlsx` and go to the **Dashboard** sheet. Click through the department slicer to filter the salary chart, or check the **Raw Data** sheet to see the underlying records the dashboard pulls from.

## Data

Synthetic dataset of 200 employee records — department, job title, salary, hire/termination dates, and performance ratings. Built to be realistic enough to demonstrate real HR reporting questions, not pulled from any real company.
